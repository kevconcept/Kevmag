☁️ Synchronisation entre appareils

Désactivée

Tous les téléphones et ordinateurs connectés au même compte partagent automatiquement les produits, ventes, acomptes, échanges et réglages du magasin, en quelques secondes. Fonctionne aussi hors ligne : l'envoi se fait au retour d'internet.

📘 Première installation (une seule fois, ≈ 10 min)
  1. Sur un ordinateur, allez sur console.firebase.google.com et connectez-vous avec un compte Google.
  2. Créer un projet → nom : kevmag-complast (Google Analytics : non).
  3. Menu Créer → Authentication → Commencer → E-mail/Mot de passe → Activer. Onglet Utilisateurs → Ajouter un utilisateur : l'e-mail et le mot de passe du magasin.
  4. Menu Créer → Firestore Database → Créer → mode production → emplacement proche (ex. europe-west).
  5. Onglet Règles de Firestore : remplacez tout par le texte ci-dessous (bouton Copier), puis Publier.
  6. ⚙️ Paramètres du projet → Vos applications → icône </> (Web) → nom « Kevmag » → Enregistrer. Copiez le bloc firebaseConfig et collez-le ci-dessous.

Le premier appareil (celui qui a déjà vos produits) choisit « cet appareil a les bonnes données ». Les autres appareils choisissent « récupérer les données du compte ».

💾 Sauvegarde

Les données sont gardées sur cet appareil seulement (iPhone et ordinateur ont chacun les leurs). Faites une sauvegarde régulièrement pour ne rien perdre.

📲 ➜ 💻 Passer les données d'un appareil à l'autre
  1. Sur l'appareil qui a les produits : touchez « Envoyer la sauvegarde » et envoyez-la (WhatsApp, e-mail…).
  2. Sur l'autre appareil : enregistrez le fichier reçu, puis « Restaurer une sauvegarde » ci-dessous.
